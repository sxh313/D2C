## 启停

在项目根目录执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\Start-Design2Code.ps1
powershell -ExecutionPolicy Bypass -File .\Stop-Design2Code.ps1
```

脚本只绑定本机地址，运行日志和任务产物写入 `.env` 指定的 `runtime` 目录。不要提交 `.env`、运行缓存或密钥。
